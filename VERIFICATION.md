# Verification

The earlier prototype's mock-data verification guide (39 curated schemes, mock DigiLocker vault, in-browser test page) has been retired, together with those mock datasets.

For how the current data and engine are verified, see:

- **TEST_REPORT.md**: unit, pipeline, end-to-end and real-data dry-run results
- **DATA_QUALITY_REPORT.md**: dataset coverage and verification statuses, generated from pipeline output
- **DATA_SOURCE_INVENTORY.md**: every source investigated and why it was or was not ingested
- **SECURITY_AUDIT.md**: security findings and fixes
